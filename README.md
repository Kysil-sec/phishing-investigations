# Phishing Investigations

A collection of documented phishing investigations, technical analysis, infrastructure research, and abuse-reporting cases.

The goal of this repository is to document real-world phishing activity while developing practical skills in:

* Phishing analysis
* OSINT
* Web and browser analysis
* Network analysis
* Infrastructure investigation
* Threat intelligence
* Abuse reporting

## Methodology

Investigations may include:

1. Initial discovery
2. Social-engineering analysis
3. Web and JavaScript analysis
4. Network/request analysis
5. Infrastructure and domain research
6. Identification of relevant providers
7. Abuse reporting
8. Documentation of the outcome

## Ethics

These investigations are conducted for defensive and educational purposes.

No real credentials, payment information, or other sensitive information is intentionally collected or exposed.

Sensitive information belonging to third parties is redacted from public reports.
